## 用語分類

Lessonごとの分類は [`data/level-0-term-tiers.json`](../data/level-0-term-tiers.json) を正本とする。

- CORE: 章の問いへ答えるために必要。初出時に本文内で定義する。
- SUPPORTING: 理解を支える。初出時に短く言い換える。
- ADVANCED: Level 0では名称と役割だけでよい。学習要求を明記し、名称暗記を修了問題にしない。

## 修正した説明依存関係

1. L0-01: `大気が連続的に薄くなる → 自然の明確な壁がない → 共通基準が必要 → 100 kmを記録に使う`へ因果順を修正した。
2. L0-03: `見えている天体 → 太陽から流れる粒 → 太陽の重力`の三基準を先に示し、各現象を説明してからカイパーベルト、ヘリオポーズ、オールトの雲と命名した。
3. L0-04: `物質の小さな単位 → 原子の中心 → 水素の原子核 → 核融合`の順にし、プラズマやニュートリノを未知語で説明しない形へ直した。
4. L0-05〜06: 宇宙住所の階層を先に完成させ、赤方偏移・重力レンズ・ダークマターなどの観測詳細は、直感説明の後にADVANCEDとして置いた。
5. L0-07〜10: `量 → 単位 → 換算 → 視差 → 見かけと実寸 → 光の移動時間`の順を維持し、数式の前に記号と学習要求を示した。
6. L0-11〜12: 最古の光を直感的に説明してからCMBと命名し、観測可能な宇宙を`情報が届く範囲`として定義してから地平線・宇宙論的距離へ進めた。
7. L0-13〜14: `届く光 → 波長 → 波長ごとの量 → スペクトル → へこみ → 吸収線 → 水素という解釈`の順へ固定した。
8. L0-15: CMB偏光と特定の初期宇宙モデルを使う急な問題を、既習のボイジャー観測とオールトの雲の推定へ置き換えた。
9. L0-18: 一般相対論・特異点・量子重力による説明をLevel 0の中心から外し、`銀河間隔の倍率 → 尺度因子という名称 → 最初期は未解決`の二段階説明へ直した。

## 問題設計の修正

- L0-01の100 km問題を、「誰が宇宙まで到達したかを同じ基準で判断する」という具体的表現へ変更した。
- L0-03の誤答選択肢から、未習の光球・事象の地平面を削除した。
- L0-05のブラックホール問題を、銀河への所属を位置と運動から判断する問題へ変更した。
- L0-10の太陽消失問題を、光の到着遅延だけで解ける問題へ変更した。
- L0-15のCMB偏光問題を、既習内容の証拠状態を比較する問題へ変更した。
- L0-18の最終問題は、ADVANCED用語の名称暗記ではなく、観測事実と最初期の具体的説明のStatus比較へ変更した。

## Lesson Standardへ反映したルール

1. 初出面にはClaim、Predict First、図表、設問、誤答解説を含める。
2. CORE / SUPPORTING / ADVANCEDを制作時に分類する。
3. `既知概念 → 直感 → 名称 → 正確な説明`の順にする。
4. 用語集は本文説明の代用にしない。
5. クイズは新しい専門語を導入しない。
6. ADVANCEDは学習要求を明記し、Level 0修了で名称暗記を要求しない。
7. Glossary Coverage 100%を公開基準とし、自動検査と人間の通し履修を併用する。

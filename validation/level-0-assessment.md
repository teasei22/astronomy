# Level 0 Parallel Assessment

更新日: 2026-08-16

## 実施上の注意

- Form AはLevel 0を見る前、Form Bは18章終了後24時間以内に実施します。
- 参加者には該当Formの「問題」だけを渡し、採点基準は渡しません。
- 教材、検索、生成AI、メモは使わず、自分の言葉で答えてもらいます。
- Form Aは20分、Form Bは25分を上限とします。空欄も結果として残します。
- Form AとBは同じ概念を異なる表現で問う並行形式です。同じ文の記憶ではなく、説明と転移を比べます。
- 各設問は0〜2点、各軸4点、総合20点です。採点者は答案を見る前にアンカーを読みます。

## Form A: Pre-test

### 問題

1. 次を小さい範囲から大きい範囲へ並べ、それぞれの包含関係を一文で説明してください。`地球 / 太陽系 / 天の川銀河 / 観測可能な宇宙`
2. `AU`、`光年`、`年`、`pc`を、距離の単位と時間の単位に分類してください。
3. 8光年先の恒星について、「地球からの距離」「今届いた光が出た時期」「恒星そのものの年齢」を区別して説明してください。
4. 宇宙の年齢が約138億年なのに、現在約465億光年先と表現される領域を観測可能な宇宙に含めるのはなぜでしょう。分からない場合は、矛盾だと思う点を書いてください。
5. 「北半球の夏は地球が太陽へ近づくから暑い」という説明を検査するには、どの観測を比べればよいでしょう。予想される結果も書いてください。
6. 二つの天体が空で同じ見かけの大きさに見え、一方が他方の10倍遠いと分かりました。本当の大きさについて何が言えますか。
7. スペクトルの656.3 nm付近で光が少ないという結果について、「観測」と「解釈」を一つずつ書いてください。
8. 「宇宙は高温・高密度の初期状態から膨張してきた」という説明を支持する、互いに異なる観測を二つ挙げ、それぞれ何を示すか説明してください。
9. 次の主張を`確立した観測・理解 / 強く支持されたモデル / 検査中の仮説 / 現在は未知`へ分類し、理由を書いてください。A: CMBが全天から届く。B: ダークマターは特定の粒子Xである。C: ダークマターの物理的正体は何か。
10. 恒星の明るさが一定周期で1%下がりました。「惑星が通過した」と結論する前に考える別の説明を二つ挙げ、区別する追加観測を一つ提案してください。

## Form B: Post-test

### 問題

1. `局所銀河群 / 太陽 / 地球 / 天の川銀河 / 太陽系`をすべて使い、地球と太陽がそれぞれ何に属するかを含めて「宇宙の住所」を二文で説明してください。
2. 地球と月、太陽系外縁、近い恒星、遠方銀河の距離を表すとき、`km / AU / 光年 / Mpc`をどこへ使うと読みやすいか対応させてください。
3. 12光年先の恒星について、12という数値から直接分かること、近傍天体としておよそ言えること、別の観測がなければ分からないことを一つずつ書いてください。
4. 130億年以上進んできた光を出した領域が、現在は130億光年より遠くにある場合があります。距離が光の移動時間より大きな数値になりうる理由を説明してください。
5. ある惑星では公転中の恒星までの距離がほぼ一定ですが、地軸が大きく傾いています。南北半球の季節、昼の長さ、恒星の高さをどう予想しますか。
6. 銀河AとBは同じ角直径に見えますが、BはAの5倍遠いと測定されました。本当の直径の比を予想し、見かけだけでは決められない理由も書いてください。
7. 水素の実験室波長より赤い側に吸収線があるスペクトルについて、検出器が記録した事実と、そこから推定する運動を分けて書き、その推定を確かめる方法を一つ挙げてください。
8. 熱いビッグバンモデルを支持する`銀河の赤方偏移と距離 / CMB / 軽元素量`が、同じ証拠の言い換えではなく独立な証拠である理由を説明してください。
9. 次の二文へASTRAEAのClaim Statusを付け、同じStatusにしない理由を書いてください。A: CMBがほぼ全天から観測される。B: インフレーションを起こした物理機構は特定の場Xである。
10. 別々の装置が同じ時刻・方向から信号を検出しました。結論が強くなる理由と、それでも確認すべき不確かさまたは代替説明を一つずつ書いてください。

## 採点基準

### 共通ルーブリック

- 2点: 結論が正しく、設問が要求する理由・区別・証拠まで具体的に示す。
- 1点: 中心概念の一部は正しいが、理由がない、重要な区別が欠ける、または軽微な誤りがある。
- 0点: 無回答、中心概念と矛盾する、または根拠なく結論だけを述べる。

### Form Aアンカー

1. `地球 → 太陽系 → 天の川銀河 → 観測可能な宇宙`とし、前者が後者に含まれると説明できれば2点。
2. AU・光年・pcを距離、年を時間に分類できれば2点。一つの誤分類は1点。
3. 距離は8光年、光は近傍なら約8年前に出た、恒星年齢は距離だけでは不明の三つを分ければ2点。
4. 光が進む間にも宇宙が膨張し、現在距離と光の移動時間は同じ量ではないと説明できれば2点。
5. 南北半球の逆の季節、太陽高度、昼の長さ、近日点が1月ごろのいずれかを使い、距離だけの予測と比較できれば2点。
6. 遠い天体の方が本当は約10倍大きいと予想し、角度だけでは距離との縮退があると述べれば2点。
7. 観測を「656.3 nm付近で受光量が少ない」、解釈を「水素吸収と整合する」のように分離できれば2点。
8. 例として銀河の距離と赤方偏移、CMB、軽元素量から二つを挙げ、異なる測定が膨張・高温初期宇宙と整合すると説明できれば2点。
9. Aを確立した観測、Bを検査中の仮説、Cを未知とし、主張の具体性と証拠の違いを説明できれば2点。
10. 黒点、伴星、背景食連星、装置誤差などから二つと、色・像の位置・視線速度・別装置など識別力のある観測を一つ挙げれば2点。

### Form Bアンカー

1. 地球と太陽はいずれも太陽系の構成天体であり、太陽系は天の川銀河に属し、天の川銀河は局所銀河群の一員だと説明できれば2点。
2. 地球・月にkm、太陽系にAU、近い恒星に光年、遠方銀河にMpcを対応させれば2点。
3. 距離12光年、光は近傍なら約12年前に出た、恒星年齢は不明を分ければ2点。
4. 膨張中の空間を光が進み、その間に隔たりが増えるため、現在距離とルックバック時間を単純に同一視できないと説明すれば2点。
5. 恒星側へ傾く半球は恒星が高く昼が長い夏、反対側は冬になり、公転の反対側で南北が逆転すると予測すれば2点。
6. 同じ角直径ならBの実直径は約5倍と予測し、角直径は実直径と距離の両方で決まると説明すれば2点。
7. 観測波長のずれと遠ざかる運動の推定を分け、複数線、校正、別時刻・別装置などで確認すると述べれば2点。
8. 三者が銀河運動、残光の放射、原子核反応という異なる時代・装置・物理過程から同じ宇宙史を検査すると説明すれば2点。
9. AをEstablished、BをHypothesisまたはActive Researchとし、観測済みの現象と具体的機構の未確定を分ければ2点。
10. 独立な誤差だけでは一致を説明しにくくなる点と、偶然一致、方向・時刻の範囲、装置固有誤差など残る確認事項を示せば2点。

## 集計

各軸は`獲得点 / 4 × 100`、総合は`獲得点 / 20 × 100`で算出します。報告では平均だけを使わず、参加者別のPre、Post、Delayed、変化量と中央値を示します。

Delayed testではForm Bの3〜10を再使用します。再受験前に正解を教えず、`獲得した改善量 = Post - Pre`、`保持率 = (Delayed - Pre) / (Post - Pre)`として扱います。分母が0以下の参加者は保持率を計算せず、得点推移をそのまま報告します。
